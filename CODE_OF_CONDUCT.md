# Code of Conduct

OpenAEO follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and patient. People here have different backgrounds and levels of experience.
- Give feedback on the work, not the person.
- No harassment, insults, sexual language or imagery, or publishing someone's private information.
- Keep issues, pull requests and discussions on topic.

This applies in every project space: issues, pull requests, discussions and reviews.

## Reporting

If someone's behaviour breaks these rules, report it to the maintainers privately. Open the **Security** tab of this repository and choose **Report a vulnerability**, and say that it is a conduct report. Only the maintainers can read it.

Maintainers will review every report and may remove comments, close threads or block an account from the project.
