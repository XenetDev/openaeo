# Security

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it and which version you used. You will get a reply as soon as we can look at it.

## Scope

OpenAEO runs a server on `127.0.0.1` that can start AI tools on your computer. Reports about that server, the stored API keys in `~/.openaeo`, the website fetcher, or content from websites and AI answers being treated as instructions are especially useful.
