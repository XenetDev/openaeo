# Licence notes

OpenAEO's own code is under the MIT licence in `LICENSE`.

The dashboard uses components from [affectUI](https://www.affectui.com). Files that begin with the line

```
// affectUI Pro – licensed under https://www.affectui.com/license, not under this project's open-source license. Don't copy it out of this project.
```

are affectUI Pro source. They are not MIT. You may run OpenAEO with them, but you need your own affectUI licence to use those files in anything else. They live under `apps/local/web/src/components/` and must not be published as a package.

The remaining affectUI files in that folder are affectUI's free components, which affectUI publishes under the MIT licence.
